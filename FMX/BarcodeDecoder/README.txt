                    README - TTMSFNCWXBarcodeDecoder demo 
===============================================================================
This README aims to clarify and address common Android-related issues when 
using the TTMSFNCWXBarcodeDecoder component in your applications.


JAR File Requirement
--------------------
For Android devices, the usage of specific JAR files is mandatory to ensure 
proper functionality of the TTMSFNCWXBarcodeDecoder component. This dependency 
is detailed here:
https://support.tmssoftware.com/t/knowledgebase-jar-file-dependency-for-
android-devices-android-support-for-fmx-applications/20058

If the JAR files are not added to the project, it will do one of the following:
- Show a black or white blank screen on startup
- Get stuck on the firemonkey logo
- Freeze or hang


Common runtime issues 
---------------------
For detailed documentation, including troubleshooting common problems and 
configuration tips for the TTMSFNCWXBarcodeDecoder component especially in
combination with TTMSFNCWXCamera, please refer to the documentation:
https://download.tmssoftware.com/doc/tmsfncwxpack/components/ttmsfncwxbarcodedecoder/
