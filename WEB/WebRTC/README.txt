=========
IMPORTANT
=========
This WebRTC demo uses TMS FNC WebSocket for the server.
If you don't have TMS FNC WebSocket installed you can use the prebuilt executable from the Server\bin folder.

=====
USAGE
=====
1. Start the server
2. Connect to the server first. You can use the same browser instance twice (2 tabs) to use one camera only.
3. The server will assign an ID for each connected client. Use this ID to connect to another client.
