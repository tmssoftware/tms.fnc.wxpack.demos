=========
IMPORTANT
=========
This WebRTC demo uses TMS FNC WebSocket for both the server and the client.
If you don't have TMS FNC WebSocket installed you can use the prebuilt executables from the Client\bin and Server\bin folders.

For this demo you need 2 camera and microphone devices!

=====
USAGE
=====
1. Start the server
2. Connect to the server first.
3. The server will assign an ID for each connected client. Use this ID to connect to another client.
